# 执行价影子记录

- 每次调仓写入账本之后，后台线程按每笔 fill 的金额读取该币永续的公开 L2 盘口（`fetch_order_book`，100 档，不需要 key）。
- 每笔记录：bid / ask / 中间价 / 价差，按金额吃单的 VWAP，用了几档；
  - 对中间价的成本（半个价差加深度冲击）；
  - 对账本收盘价的成本（还包含 00:00 UTC 收盘到快照之间的价格漂移）；
  - 偏差 = 对中间价的成本 − 假设滑点（手续费两边相同，不计入）。偏差 > 0 表示假设偏乐观。
- OKX 永续盘口的数量单位是“张”，按 `contractSize` 换成币数量；Binance USD-M 本来就是币数量。
- 补跑日记为 `skipped_catchup`（补跑时的盘口跟那天收盘无关）；盘口太薄记为 `partial`；读取失败记为 `error`。
- 只写 `data_dir()/exec_shadow.sqlite` 的 `quotes` 表。账本不读它，成交价不变，纸面与回测的一致性不受影响。`AUU_EXEC_SHADOW=off` 可关闭。
