# 策略绩效报告页（P1-1 + P1-2）

- 页面 `/performance`（控制台“趋势策略”卡片右上角的“绩效报告 →”）。数据接口 `GET /api/v1/mainstream/strategy/report`，必须登录：没有会话返回 401，路由本身也会再检查一次。前端由 AppShell 跳到登录页。
- 页顶显示 Go/No-Go 判定和日收益年化 95% CI（block bootstrap，与判定同一套方法），放在所有指标之前，避免只挑好看的数字。
- 指标：累计收益、CAGR、Sortino、Calmar、Sharpe、最大回撤及发生日、最长/当前回撤持续天数、日胜率、日盈亏比（这个策略不是逐笔开平仓，所以用“日”代替“笔”）。不足 30 天时，年化类比率不显示。
- 月度收益热力图（按 UTC 月复利），净值曲线和回撤曲线。
- 逐币归因（USDT）：
  - 价格 = 前一日权重 × 涨跌；
  - 资金费 = −权重 × 资金费率，费率逐币从行情库的结算记录取；
  - 成本 = fills 和 risk_fills 的手续费 + 滑点。
  - 盘中风控调整按 `adjustments` 分段累加。
  - 页面显示“未归因残差”，不做隐藏（测试中风控关闭时残差约为 0）。
- 只读账本，不改任何策略或记账逻辑。界面是自己写的，没有使用 FreqUI 代码。
