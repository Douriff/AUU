# 现货筛币（只读，独立页面）

独立测试页，不进入现有主导航，不改旧行情页和交易路径。本变更不合并且不部署。

## 地址

- 页面：`/screener`（不在现有导航里。浏览器里的订阅预览锁仍按原名单挡住未预览的访客，但那不是权限。）
- `GET /api/v1/screener/spot`：字段白名单、币池说明、K 线口径。不含价格。
- `POST /api/v1/screener/spot`：只读筛选。不写账本、不下单。
- `POST /api/v1/screener/spot/csv`：导出。每个单元格加引号，以 `=` `+` `-` `@` 或制表符开头的内容加撇号，避免表格公式。

## 谁可以读

服务端没有行情订阅记录。`apps/web/src/lib/subscription.ts` 写明只是本机显示预览，不代表权益。积分目录里唯一的商品是示例徽章 `example_badge`，不作为行情权限。因此这三条接口不读取 localStorage、请求头或该徽章，也不新建扣款。

账号开启时：

| 调用者 | GET / POST / CSV |
| --- | --- |
| 未登录 | 401 `AUTH_REQUIRED`（沿用原登录门，路径不在公开名单） |
| 已登录但不是管理员 | 403 `SCREENER_ADMIN`，响应里没有行情 |
| 管理员会话 | 允许 |

账号关闭时没有管理员会话，三条接口同样 403。`AUU_SCREENER_FIXTURE=1` 不能跳过这次检查。页面收到 403 只显示“仅管理员预览”，不渲染价格。

共享登录门对旧路径的判定没有改。已登录的非管理员仍然可以访问原来的行情接口；只有新筛币路由多了这一层。

响应里 `liveEnabled` 恒为 `false`，`orderMode` 为 `paper`。`AUU_LIVE_ENABLED` 不能把这个接口变成实盘。

## 注册点（仅此三处碰到旧文件）

1. `apps/api/app/main.py`：挂上新的 router。根路径 `/` 的目录没有加筛币条目。
2. `apps/web/src/app/router.tsx`：增加子路由 `screener`。`AppShell` 的桌面导航和底部标签未改。
3. `apps/web/src/lib/subscription.ts`：把 `/screener` 放进既有行情锁名单。`/news`、`/settings`、`/login`、`/subscribe`、`/airdrops` 以及原来的行情路径锁定关系不变。

## 口径

- **最新价、24 小时计价成交额**：币安现货 24 小时 ticker 的 `lastPrice` / `quoteVolume`。不是日 K 收盘价。响应保留本机抓取时间，以及 ticker 自带的 `closeTime`（取本批最早的一条，避免把整批说得比最旧的成交更新）。
- **EMA 10 / 20 / 200、RSI 14**：只用**已经收盘**的日 K（`closeTime < 服务器当前时间`）。当天未收盘的那根日 K 会标明并排除，不参与指标。
- 指标只有一份实现（`app/screener/logic.py`）。比较用原始浮点，展示时的四舍五入不参与判断。
- 平价：已收盘日 K 的涨跌全是 0 时，RSI 14 定义为 **50**。只涨为 100，只跌为 0。数据不够、NaN、非正价格得到的是未知，不会用 0 代替。
- 组合是三值：`true` / `false` / `unknown`。`all` 里有未知就不能算通过；`any` 里没有确定的 true 时，未知也不能算不通过。`not` 不把未知变成通过。通过只等于 true，不通过只等于 false。
- 上穿 / 下穿未实现，请求里出现会被拒绝，界面也不能选。EMA 只允许 10、20、200，周期只允许 `1d`。没有“不支持却默认 EMA 50”。

## 币池与抓数

币池是币安现货、计价 USDT、`status=TRADING`、且允许现货交易的交易对。不是全市场新币雷达，也不是成交额前 N。永续、停牌、非现货会被拒绝。价格接近 1 的币（例如稳定币）不会因此被删掉。

历史够不够按**当前条件**判断：能算 EMA 10 的新币不会因为还不够 EMA 200 就被移出币池；缺的那个指标是未知。

抓数是公开 REST，不带密钥，沿用现有的 `BINANCE_REST_URL`。交易状态白名单只有 `TRADING`。同一资源的并发请求会合并；日 K 有并发上限，并遵守 `Retry-After`。空响应或失败**不覆盖**上一份有效数据，并把该快照标成过期；过期值可以显示，但不能当成当前命中。

策略池里仍新鲜的日 K（主流行情库，只读）优先于再向交易所要一遍。筛币不启动全站 WebSocket，也不去拨主流行情的刷新循环。

`AUU_SCREENER_FIXTURE=1` 才会使用内置样本。默认关闭。样本响应带 `fixture: true`，页面会标明这不是实盘行情。

## 部署与回滚（本 PR 不做）

没有数据库迁移，没有用户数据、密钥、DNS 或实盘开关的改动。缓存只在进程内存里。

以后若要上线：用现有的 API / Web Dockerfile 重建镜像即可，不要设置 `AUU_SCREENER_FIXTURE`，不要为了这个功能打开 `AUU_RT_WS`，不要改 `AUU_LIVE_*`。只有管理员会话能打开 `/screener` 并读到行情。普通登录账号会看到拒绝说明，接口返回 403。行情订阅若要以后接上，需要先有服务端记录，不能用浏览器标记代替。

回滚：把 API 和 Web 镜像换回上一版（或 revert 这次提交后再构建）。没有要清的表，也没有要改的 DNS。进程重启后内存缓存自然消失。
