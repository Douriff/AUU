# 安全审计与加固（2026-10-11，PR #87）

## 范围
OWASP Top 10 对照全部 /api 路由（主流模式 + legacy 关闭）、nginx/Cloudflare 链路、依赖（pip-audit、npm audit）、前端构建产物。

## 已有且复核通过
- 登录门（`app/auth/gate.py`）：除 health/status/登录注册流程外 /api 与 websocket 全部要登录；系统写操作仅管理员。
- CSRF：写请求与 websocket 握手校验 Origin（同站或 CORS_ORIGINS），Sec-Fetch-Site=cross-site 拒绝；Cookie `HttpOnly; Secure; SameSite=Lax`。
- 账号锁定（10 次/15 分钟）、邮箱验证码：同邮箱 60 秒重发、每 IP 10 次/小时、输错 5 次作废、10 分钟有效；TOTP 票据限次。
- 积分账本：只追加（触发器拒绝 UPDATE/DELETE）、哈希链、幂等键按动作+操作人命名空间（不能跨用户重放）、指纹不一致 409、金额符号与上限校验、管理员写入每次都要密码+2FA；未发现绕过。
- 注入：SQLite 全部参数化；无 shell/模板拼接用户输入。
- 越权：纸面账户按会话用户取，看他人账户需管理员；points 只读自己的账。
- 客户端 IP：Cloudflare → nginx（`real_ip_header CF-Connecting-IP`，仅信任 Cloudflare 网段；AOP 强制 mTLS，ufw 只放行 Cloudflare）→ `X-Forwarded-For` → uvicorn（只信任 127.0.0.1）。应用拿到的就是真实 IP；客户端自带的 CF-Connecting-IP / XFF 被忽略（有测试）。

## 前端反编译的说明
- 前端代码无论怎样处理都能在浏览器里被读到。真正的保护是：密钥、内部地址、策略逻辑都不在前端。已检查 src：没有密钥/令牌/服务器 IP；只引用 `api.devnet.solana.com`（公开 RPC）和 solscan 链接；策略计算全部在服务器。
- 评估了 javascript-obfuscator（最轻配置，关掉控制流平坦化）：主包 1.21 MB → 2.41 MB，gzip 376 KB → 675 KB（+80%），还会拖慢手机首屏解析。收益只是增加阅读成本，**不采用**。
- 注意：策略参数（lookbacks、目标波动率、仓位上限）与调仓明细由接口发给**已登录用户**展示，这是产品透明度设计，不属于前端泄露；若要对普通用户隐藏，需要单独做产品决定。

## 遗留
- npm 仍有 14 high / 16 moderate：全部来自 @solana wallet-adapter 依赖链（react-native/metro 开发工具，不打进浏览器包）和 vite 5 开发服务器（只影响本地 dev server）。修复需要升 vite 8 和换钱包适配器，单独做。
- multidict 6.7.1（CVE，需 6.9.1）被 ccxt 4.5.85 精确锁定，升级 ccxt 会影响行情抓取，单独评估。
- 限流计数在进程内存，重启清零；单进程部署足够，多进程需改为共享存储。
- 账号锁定按用户名计数：别人可以故意输错让某账号锁 15 分钟（可用找回密码/稍后重试）；Cloudflare 限速规则可以减轻。
